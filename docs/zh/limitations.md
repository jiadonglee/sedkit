# 模型覆盖与已知限制

[English](../en/limitations.md) · [GitHub](https://github.com/jiadonglee/spbin)


| 路线 | 主要支持范围 | 关键限制 |
| --- | --- | --- |
| 普通恒星网络 | 2800–7498 K；年龄 0.5–10 Gyr；[M/H] −1 至 +0.5 | 主序矮星；可用质量随年龄和金属丰度变化 |
| 稀疏超冷区域 | 2313–2929 K 的部分标签区域 | 具有数值支持，精度尚未验证 |
| 热主序星 | 7000–30000 K；log g 3–4.75；[M/H] ±0.3 | `hot=True` 的共同拟合掩码仅为 XP 与 J/H/Ks |
| 红巨星模板 | 3600–6800 K；log g 0–3.8；[M/H] −2.6 至 +0.6 | 需要标签先验；热主序伴星扫描 |
| 热亚矮星 | 20–45 kK；log g 5–6.5 | 富氦层级从 32 kK 起 |
| DA 白矮星 | 6–80 kK；log g 7–9.5 | 质量–半径与冷却表需同时支持；>40 kK 实测验证较弱 |

拟合输出是局部最优解。`converged=True` 表示优化器收敛；模型支持范围表示可计算范围。两者都不能独自说明物理模型正确。

测量误差以对角形式进入当前似然；低秩模型误差保留相关性及其行列式。这里没有直接使用完整 Gaia XP 测量协方差。W1/W2 默认在基础拟合中留出；Gaia G<9 时 SPHEREx 段被排除。暖星网络的 SPHEREx 预测缺少对应暖星训练光谱，尤其约 6400 K 以上需谨慎。

消光 E 是原生 ZGR23 量，不能直接当作 E(B−V) 或 A_V。消光曲线固定，宽带衰减采用名义波长近似；地图也使用 Gaia XP 信息，先验与光谱并非完全独立。热星的温度与消光、暖主星的年龄与伴星光度存在退化。

各 API 的 `delta` 符号和基准不同，见各接口说明。它们均不直接给出双星概率、Bayes factor 或统一显著性。白矮星光度包络没有校准置信覆盖；巨星阈值依赖其控制样本和配置。跨路线的不同掩码或目标函数不能直接排序。

默认 SPHEREx 孔径提取没有包围能量修正、逐曝光自行跟踪或邻星去混合；拥挤、高自行目标需进一步检查。DR4 参数接口保留了扩展空间，服务兼容性尚未验证。基础 `fit` 不提供通用巨星、棕矮星、三合星或混合源模型。
