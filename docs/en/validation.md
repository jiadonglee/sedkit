# Validation evidence

[中文](../zh/validation.md) · [GitHub](https://github.com/jiadonglee/spbin)


| Question | Existing result | Evidence |
| --- | --- | --- |
| Cool-binary mass ratio | One Gaia SB2 has q_SED≈0.840 versus q_RV≈0.868 | [General validation](../validation.md) |
| Warm-star scale | Cluster masses typically 0.02–0.05 solar masses below isochrone values; free ages older | [Warm-star validation](../validation-warm.md) |
| Hot-star spectral shape | 44 held-out anchors, about 1.2–1.4% XP shape agreement | [Hot-star validation](../validation-hot.md) |
| Giant injections | About 87% recovery at 20–30% companion blue-light contribution | [Giant validation](../validation-giant.md) |
| Single sdBs | 157 out-of-fold stars; about 1.7 kK temperature scatter with blue XP | [Subdwarf validation](../validation-subdwarf.md) |
| Single-DA absolute scale | 289 independent stars; Teff bias +1.40%, robust scatter 3.54%; absolute XP bias +1.90%, about 14% source scatter | [WD validation](../validation-whitedwarf.md) |

These results apply to the respective experimental configurations. Linked validation pages define samples, selection and assumptions. Individual companion interpretations need independent observational support.
