    公开接口签名索引¶

    English · GitHub

    以下列出顶层导出、主要类方法、轨道接口和诊断工具的参数与默认值。* 后的参数必须使用关键字；类方法省略 self/cls。SED.metadata 的默认值是独立空字典；wavelength_um 是属性。EdenhoferPrior.penalty 为静态方法。DATALINK 是 Gaia 模块的默认服务 URL 常量。内部实现函数不属于这个公开接口索引。
